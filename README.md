# Telegram Glass

Web (React + TypeScript + Vite + Tailwind CSS) port of the imported Android/Jetpack Compose `TelegramGlass_Android17_iOS26_v2` application.

## Features
- **Liquid Glass UI**: Translucent glass cards, headers, search bar, and floating message composer with gradient specular borders and backdrop blur.
- **Animated Mesh Background**: Smoothly drifting radial gradient blobs over a `#070B14` canvas.
- **iOS 26 Spring Transitions**: Slide + parallax + scale push/pop navigation between the chat list and conversation view.
- **Scroll-to-Top Clock Gesture**: Tap/click the live `HH:mm` clock in the status bar or header pill (`InteractiveClockPill`) to smoothly scroll back to the top.
- **Interactive Chat & Search**: Real-time chat search filtering and sending messages with spring pop-in animation.

## Running
```bash
npm install
npm run dev
```
